# Your technology choices and why
I chose **React** and **Styled Components** to build this application. I wanted to showcase my proficiency with these technologies, as they are a strong match for Knotch's tech stack. The component-based architecture of React allowed me to build a dynamic and accessible user interface, while Styled Components provided a maintainable and scoped approach to styling each component.

# What you'd improve with more time
- Clean up the console warnings and errors.
- Add unit and integration tests for the components to ensure reliability.
- Complete the dark mode styles and ensure a seamless user experience across themes.
- Improve initial load time using code splitting or lazy loading.

# Any assumptions or trade-offs you made
A key design trade-off was prioritizing simplicity over complexity. The application does not currently cache previous generations, which means that the app's initial load time will increase as more generations are added. With more time, I would implement a caching strategy to mitigate this.
